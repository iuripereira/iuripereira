## How I work with AI

Not "I use ChatGPT sometimes". This is my actual operating model:

- **Specs before prompts.** Every non-trivial task starts as a written spec — scope, constraints, acceptance criteria. The agent executes against it; I review the diff, not the vibe.
- **Agents wired into real systems.** MCP servers connecting Claude Code to Jira, Atlassian Rovo, Todoist, Google Workspace, banking and internal APIs — so automation touches production data, not toy examples.
- **Custom skills over one-off prompts.** Recurring workflows become versioned skills in Git, reviewed and improved like code.
- **Governance mindset applied to AI.** Same instincts I bring to ITSM: traceability, defined ownership, measurable outcomes, and honesty about what the system actually does.
